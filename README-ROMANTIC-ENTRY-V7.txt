REISEZEIT ROMANTIC ENTRY V7

- Romantischer, lebendiger Reise-Startbildschirm mit Horizontmotiv
- Funktionaler Login direkt im Startbereich
- Login verschwindet unmittelbar nach erfolgreicher Anmeldung
- Danach öffnet sich die Reiseauswahl / Reiseerstellung
- Bei vorhandenen Reisen kann direkt ausgewählt werden
- Ohne vorhandene Reise führt der Einstieg zur Erstellung
- Cloud-Verbindung kann nach einem Login ohne Seitenreload neu starten
- Reisebereiche bleiben vor Anmeldung vollständig gesperrt
